# JACKING 中継 + Web サーバー

JACKING をブラウザで遊ぶための「ゲーム配信」と「オンライン対戦の中継」を 1 つにまとめた
サーバーです。1 か所にデプロイすれば、そこの URL を開くだけで対戦も観戦もできます。

このサーバーはゲームのルールを一切知りません。やっているのは次の 2 つだけです。

1. `public/` の中身(ゲーム画面)をそのまま配信する
2. 「部屋(ID + パスワード)」の中でメッセージを転送する
   - **対戦者は最初の 2 人**。相手の手をそのまま相手へ転送します。
   - **3 人目以降は観戦者**。対戦者が送ってくる「盤面まるごとのスナップショット」を
     受け取って表示します。途中から入ってきた観戦者にも、キャッシュしておいた
     最新のスナップショットをすぐ渡します。

## ローカルで試す

```
npm install
npm start
```

`http://localhost:8787` をブラウザで開くとゲームが始まります。中継も同じポートで
待ち受けるので、「中継サーバーURL」欄は自動で `ws://localhost:8787` が入ります
(通常はそのままでOK)。

複数人での動作を確認するには、同じ URL をブラウザのタブ / ウィンドウで複数開き、
1 つで「部屋を作る」、残りで「部屋に入る」を実行します。

### テスト

```
node smoke-test.js     # 中継サーバー単体(部屋・観戦・スナップショット配信)
```

## インターネット上に公開する

このフォルダ(`jacking-relay`)ごと 1 か所にデプロイするだけです。以前のように
プレイヤーが各自 URL を入力する必要はありません。発行された URL を共有すれば、
その URL を開いた人が対戦・観戦できます。

### おすすめ: Render.com (無料枠あり)

1. https://render.com にサインアップ(GitHub アカウントでOK)
2. このフォルダを GitHub リポジトリに push
3. Render のダッシュボードで **New +** → **Web Service** を選び、そのリポジトリを選択
4. 設定:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free でOK
5. デプロイが終わると `https://<サービス名>.onrender.com` の URL が発行されます
6. **この URL をそのまま共有してください。** 開いた人がゲームを遊べます。

無料プランは一定時間アクセスがないとスリープするため、しばらく誰も使っていないと
最初の接続に数十秒かかることがあります。

### 他の選択肢

Node.js が動く場所ならどこでも構いません(Railway、Fly.io、VPS、自宅サーバーなど)。
ポートは環境変数 `PORT` から読み込みます(未設定時は 8787)。HTTP と WebSocket は
同じポートを共有します。

## 部屋の仕組み

- 部屋を作ると 6 文字の部屋ID(例: `HN73BC`)が発行されます
- 部屋には自分で決めたパスワードを設定します
- **最初に入った人が対戦相手、それ以降に入った人は観戦者**になります
  (観戦者は両プレイヤーの手札を含めて盤面をすべて見られますが、操作はできません)
- 部屋の上限は 64 人(対戦 2 + 観戦 62)
- 共有リンク `https://<URL>/?room=<部屋ID>` を開くと、入室画面に部屋IDが入った状態で開きます
- 誰も入らないまま 30 分経った部屋は自動的に破棄されます
- 全員が退出した部屋は破棄されます

## プロトコル

```
client -> server:
  {t:"create", pass}                  部屋を作る(作成者が p1)
  {t:"join", room, pass}              入室。対戦枠が空いていれば p2、埋まっていれば観戦者
  {t:"relay", data}                   もう一方の対戦者へそのまま転送
  {t:"snapshot", data, rev}           盤面まるごと。キャッシュして観戦者へ配信

server -> client:
  {t:"created", room}
  {t:"joined", room, seat}            seat は "p2" または "spec"
  {t:"ready"}                         対戦者が 2 人そろったら両方へ
  {t:"relay", data}
  {t:"snapshot", data, rev}           現在の盤面(観戦者向け)
  {t:"want_snapshot"}                 観戦者が入ってきたので最新スナップショットを送ってほしい
  {t:"spectators", count}             観戦者数(全員へ)
  {t:"peer_left", who}                who: "player" | "spectator"
  {t:"err", reason}                   need_password | not_found | bad_password | room_full
```

## ファイル構成

- `server.js` — 中継 + 静的配信サーバー本体
- `public/index.html` — ゲーム画面(対戦 + 観戦)。`jacking-windows/Web/index.html` と同一
- `package.json` — 依存関係(`ws`)
- `smoke-test.js` — 中継サーバーの簡易動作確認スクリプト
